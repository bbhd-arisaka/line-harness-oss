# beyond line 引き継ぎ(Chrome拡張機能)

Lステップから、友だち・タグ・友だち情報・フォーム回答・トーク履歴を集めて、beyond line の「データ引き継ぎ」画面に渡す拡張機能。
集めたデータは、拡張機能の中(自分のPCのChrome)にだけ保存し、外部には送らない。beyond line 画面で取り込んだあと、画面から削除できる。

収集パッケージの形は `PACKAGE_FORMAT.md`。画面側の変換は `apps/web/src/lib/lstep-migrate/`。

## 入れ方(最初の1回だけ・約1分)

1. Chrome のアドレス欄に `chrome://extensions` と入れて開く
2. 右上の「デベロッパー モード」をオンにする
3. 左上の「パッケージ化されていない拡張機能を読み込む」を押す
4. このフォルダ(`apps/lstep-extension`)を選ぶ → 「beyond line 引き継ぎ(Lステップ)」が一覧に出れば完了
5. すでに開いている Lステップ・beyond line のタブは、再読み込みする

## 使い方(アカウントごとに・約10分、ほぼ待つだけ)

1. Chrome で Lステップにログインし、引き継ぎたいアカウントに切り替える(右上のアカウント名)
2. 右下に出る黒いパネルで、アカウント名を確認して「収集を開始」を押す
3. 画面が何度か切り替わる。**このウィンドウを前面に出したまま**待つ(途中で止めても、「収集を開始」で続きから再開できる)
4. 「収集が終わりました」と出たら「beyond line で取り込む」を押す → beyond line の「設定 → データ引き継ぎ」が開く
5. 取り込み先のアカウントを選び、確認して反映する

## 仕組み

- `lstep-content.js` … Lステップの画面で動く。画面を移動する手順(一覧・CSV・定義・フォーム)があるため、進み具合を `chrome.storage.local` に残して、移動後に続きから再開する。
- `background.js` … 集めたデータの置き場(IndexedDB)。Lステップの画面と beyond line の画面は別のサイトなので、この拡張機能が間に入って受け渡す。
- `bridge.js` … beyond line の画面からの「集めたデータをください」に答える(一覧・取得・削除のみ許可)。
